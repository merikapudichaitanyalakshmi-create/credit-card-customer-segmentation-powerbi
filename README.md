# 📊 Credit Card Customer Segmentation Dashboard

## 🔍 Project Overview

This project analyzes customer behavior for a credit card business using an interactive Power BI dashboard.
The goal is to identify **revenue drivers, customer segments, and churn risk patterns** to support data-driven decision-making.

---

## 🎯 Objectives

* Analyze customer transaction behavior
* Segment customers based on value and usage
* Identify high-revenue and high-risk customer groups
* Detect inactivity trends that may indicate churn

---

## 🧰 Tools & Technologies

* **Power BI** – Data visualization & dashboard creation
* **DAX (Data Analysis Expressions)** – Measures and calculated columns
* **CSV Dataset** – Customer transaction and demographic data

---

## 📊 Dashboard Features

### 🔹 Key Performance Indicators (KPIs)

* Total Customers
* Total Revenue
* Total Transactions
* Revenue per Customer
* Average Transaction Value
* Average Credit Limit

---

### 🔹 Customer Segmentation

* Customers categorized into:

  * High Value
  * Medium Value
  * Low Value
* Based on transaction amount and utilization behavior

---

### 🔹 Revenue Analysis

* Revenue distribution across income groups
* Identification of key revenue-generating segments

---

### 🔹 Customer Behavior Analysis

* Scatter plot showing:

  * Credit Limit vs Utilization Ratio
  * Each point represents an individual customer
  * Bubble size indicates transaction value

---

### 🔹 Top Customers

* Top 10 customers ranked by transaction count
* Helps identify high-engagement users

---

### 🔹 Risk & Churn Insights

* Active vs Inactive customer trends over time
* Churn risk peaks identified around mid-tenure (months 35–40)

---

## 💡 Key Insights

* Low-income customers generate the highest revenue, indicating frequent transaction behavior
* Majority of customers fall into the medium-value segment, suggesting strong upsell potential
* Customer inactivity peaks during mid-tenure, highlighting a critical churn window
* Higher credit limits do not always correlate with higher utilization

## 📁 Dataset

The dataset includes:

* Customer demographics (age, gender, education, marital status)
* Account details (credit limit, tenure, relationships)
* Transaction metrics (amount, count, utilization ratio)

## 🚀 How to Use

1. Download the `.pbix` file from this repository
2. Open it in Power BI Desktop
3. Interact with filters (income, education, gender, etc.)
4. Explore insights across different customer segments
